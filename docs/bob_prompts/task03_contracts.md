# Etch — Task 3: contract compiler, "Etch it" endpoint, CI gate

Compile a drawing into an import-linter `.importlinter` file, write it into the target repo via `POST /api/etch-it`, and add a GitHub Actions workflow that blocks PRs which break the drawing. The tests already exist and are the spec.

## Scope (strict)
- **Edit:** `backend/etch/contracts.py`, `backend/etch/main.py`.
- **Create:** `.github/workflows/etch-architecture.yml`.
- **Read only** those files plus `backend/etch/models.py`, `backend/tests/test_contracts.py`, `backend/tests/test_workflow.py`, and the tests in `backend/tests/test_api.py` from `DRAWING = {` downwards.
- **Do NOT modify** tests, fixtures, `models.py` (`EtchItResponse` already exists), or frontend/demo-app files. Don't install anything; `backend/.venv` has import-linter 2.15.
- **Windows PowerShell:** call Python as `.venv\Scripts\python.exe`. No servers, no git.

## 1. `backend/etch/contracts.py`: `compile_contracts(drawing, root_package) -> str`

Semantics: a drawn arrow A→B means "A may import B". Every drawn box gets one `forbidden` contract listing the drawn boxes it has no arrow to.

1. `drawn` = sorted unique `drawing.layers`.
2. `allowed[src]` = sorted targets of arrows where src and target are both in `drawn` and src ≠ target. Ignore other arrows.
3. For each `src` in `drawn` (sorted):
   - `forbidden` = the other drawn layers not in `allowed[src]`, sorted.
   - Skip `src` if `forbidden` is empty.
4. The output must match `test_exact_output_...` byte for byte:
   - Line 1 is exactly `# Generated by Etch from your architecture drawing. Redraw in Etch instead of editing by hand.`
   - Then `[importlinter]` and `root_package = <root_package>`.
   - Then, for each contract: a blank line, `[importlinter:contract:etch-<src>]`, `name = <src> may only import: <allowed joined by ", " or "nothing">`, `type = forbidden`, `source_modules =` followed by one `    <root>.<src>` line, `forbidden_modules =` followed by one `    <root>.<f>` line each, and `allow_indirect_imports = True`.
   - Module lines are indented 4 spaces, and the text ends with exactly one `\n`.
   - `allow_indirect_imports = True` is essential. import-linter's default also forbids indirect chains, so a legal `api → services → db` would wrongly break "api must not import db".
5. Keep it pure: string building only, and import only from `etch.models`.

## 2. `backend/etch/main.py`

Add `POST /api/etch-it`, which takes a `CheckRequest`, returns an `EtchItResponse` and is a plain `def`:
- `repo = resolve_repo(req.repo_path)`, which already raises 400.
- Build `text = compile_contracts(req.drawing, req.root_package)`.
- Write it with `(repo / ".importlinter").write_text(text, encoding="utf-8", newline="\n")`. `newline="\n"` is required so Windows doesn't write CRLF.
- Return `EtchItResponse(written=[".importlinter"], importlinter=text)`.

Import `EtchItResponse` from `etch.models`. Change nothing else.

## 3. `.github/workflows/etch-architecture.yml` (repo root)

- **Name:** `Etch architecture gate`.
- **Triggers:** `pull_request`, `push` to `main`, and `workflow_dispatch`.
- **Permissions:** `contents: read`.
- **Job `architecture`** (ubuntu-latest, `defaults.run.working-directory: demo-app`):
  1. `actions/checkout@v5`
  2. `actions/setup-python@v6` with `python-version: "3.12"`
  3. `pip install import-linter==2.15`
  4. A step named `Code must obey the Etch drawing`, with `if: hashFiles('demo-app/.importlinter') != ''`, that runs `lint-imports --no-cache`
- **Job `tests`** (ubuntu-latest, runs from the repo root):
  1. checkout, then setup-python 3.12, as above
  2. `pip install -e "backend[dev]"`
  3. `python -m pytest -q backend`
  4. `python -m pytest -q demo-app`
