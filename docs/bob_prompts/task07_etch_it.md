### `gitops.py` (add; keep `GitError` and `discard_changes`)
- **`current_branch(path) -> str`:** `git -C path rev-parse --abbrev-ref HEAD`.
- **`compare_url(remote_url, branch, base) -> str | None`:**
  - GitHub remotes only. Handle `https://github.com/o/r(.git)` and `git@github.com:o/r(.git)`.
  - Return `https://github.com/o/r/compare/{base}...{branch}?expand=1`, or `None` for any other host.
- **`snapshot_branch(path, branch, message) -> str`:** commit the current state of `path`'s folder on top of `HEAD` into `branch`, **without** changing the checkout, the index or the current branch. Use a temporary index file:
  1. Run the git commands with `env GIT_INDEX_FILE=<a temp file>`, starting with `git -C path read-tree HEAD`.
  2. `git -C path add -A -- .`, so only the folder is added.
  3. `tree = git -C path write-tree`.
  4. `sha = git -C path commit-tree <tree> -p HEAD -m <message>`.
  5. `git -C path update-ref refs/heads/<branch> <sha>`. The branch is re-created from `HEAD` each time.
  6. Delete the temp index and return `sha`.

  If it isn't a git repo, or any step fails, raise `GitError`.
- **`push_branch(path, branch) -> bool`:**
  - Returns `False` if `git -C path remote get-url origin` fails.
  - Otherwise runs `git -C path push -f origin <branch>` with a 120s timeout and returns whether it succeeded.
- **`origin_url(path) -> str | None`.**
