# IBM Bob 2.0 Hackathon — rules summary
Source: https://lablab.ai/ai-hackathons/ibm-bob-2-hackathon · Guide: https://lablab-ibm-bob-2-hackathon-guide.s3.us.cloud-object-storage.appdomain.cloud/index.html

- Deadline: Sep 27, 21:00 Dhaka / 11:00 ET.
- Challenge: improve a specific developer workflow; working prototype built with IBM Bob 2.0; use Agent mode, parallel tasks, subagents, document understanding; show measurable impact.
- Judging: Application of Technology (completeness + clear Bob 2.0 use) · Presentation · Business Value · Originality.
- Deliverables: title, short + long description (Problem & Solution ≤500 words), IBM Bob Usage Statement (≤500 words), tags; public repo with Bob-assisted code + `bob_sessions/` screenshots (PNG); demo platform + app URL; cover image; MP4 video ≤3 min (≥90 s of product in action, narrated, show Bob usage); slide deck.
- Bob IDE required (v2.0.2+). Bob Shell optional. 40 Bobcoins, no top-ups.
- Optional: watsonx Orchestrate / watsonx.ai / STT / TTS / Cloudant via hackathon IBM Cloud account ($80).
- Data: own data only; no PII, client/confidential, or social-media data.
